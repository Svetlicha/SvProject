# SvProject

Защитена web версия на хотелския работен проект. Публичното GitHub Pages хранилище съдържа само приложението; оперативните данни се пазят в Supabase и се зареждат след успешен вход.

## Сигурност

- Supabase Auth проверява потребителя преди приложението да бъде заредено.
- Няма публична регистрация в интерфейса.
- Row Level Security ограничава всеки ред до неговия `owner_id`.
- Пароли и service-role ключове не се записват в кода или GitHub.
- `assets/supabase-config.js` съдържа само публичните browser настройки. Supabase publishable/anon ключът е безопасен единствено при включени и проверени RLS правила.

## Данни

State-ът е разделен между:

- `app_weeks` - седмици и хотелските им данни;
- `app_tasks` - задачи по дати;
- `app_discount_reservations` - резервации с отстъпки;
- `app_attendance_records` - дневните записи от Формата;
- `app_documents` - настройки и по-малки секции;
- `app_backups` - ограничен брой ръчни backup-и.

SQL схемата е в `supabase/migrations/20260823_initial_schema.sql`.

## Локална проверка

Стартирай статичен HTTP сървър в корена и отвори `index.html` или `mobile.html`. Без валидна Supabase конфигурация се показва само заключеният Login екран и основното приложение не се зарежда.
